15. 예외/스레드

예외

try {
    예외가 발생할 가능성이 있는 코드
} catch( 예외종류 변수 ) {
    예외 발생시 실행할 코드
} finally {
    예외와 상관없이 무조건 실행할 코드
} 		          접근권한 자료형y 메서드이름(전달인자) throws 예외클래스 {
    예외가 발생할 가능성이 있는 코드
    return y;
}
 
 
 


Exception   프로그램 실행 중 발생하는 오류 상황을 나타내는 객체로, 비정상적인 동작을 처리하기 위해 사용

try   try-catch-finally 문의 시작을 나타내고, 중괄호안에 예외가 발생할 가능성이 있는 코드를 포함

catch   try-catch-finally 문에서 예외 발생시 실행할 코드를 기술

finally   try-catch-finally 문에서 예외 발생여부와 상관없이 무조건 실행할 코드를 포함하며 생략 가능

throws   해당 메서드에서 예외가 발생하면 지정한 예외 클래스로 보내서 처리

IOException   입출력시 발생할 수 있는 예외를 처리하기 위한 클래스

NumberFormatException   숫자 형식 불일치 예외
예) Integer.parseInt("10")는 올바르게 실행되지만, Integer.parseInt("a")는 예외 발생

ArrayIndexOutOfBoundsException   배열의 허용 범위 초과 예외
(0<=배열인덱스<배열길이)이므로, (배열인덱스<0) 또는 (배열길이<=배열인덱스)이면 예외 발생

InputMismatchException   입력 자료형 불일치 예외
예) 정수형 데이터를 읽어오는 nextInt()에 "10"을 입력하면 올바르게 실행되지만, "a"를 입력하면 예외 발생

ArithmeticException   산술 연산 오류
예) int variable = 4/0; // 결과값이 무한대이므로 유한한 메모리 공간에 저장할 수 없으므로 예외 발생

NullPointerException   빈 객체 접근 오류
예) String variable = null;  System.out.println( variable[0] );

스레드

Thread   메인 스레드와 별개로 작동하며, 계속 대기하고 있다가 특정 이벤트가 발생하면 활성화
예) 캐스터네츠, 트라이앵글, 탬버린를 담당하는 각 스레드(연주자)는 자신의 박자에만 집중하여 연주

start   스레드를 시작하는 메서드

run   스레드를 시작하는 메서드에서 호출하며 실질적으로 스레드 작업을 수행

sleep   스레드를 일정 기간동안 실행을 중지하며, 밀리초가 기본단위로 1000이면 1초 중지
